Die Idee des Spiels

Kurz gesagt: Land erobern, damit Geld verdienen, eine Armee bauen, den Krieg gewinnen.

Wer spielt?

Jeder Spieler führt eine oder mehrere Nationen. Die Nationen sind nacheinander dran, immer in derselben Reihenfolge. Waren alle einmal dran, ist eine Runde vorbei.

              … eine nach der anderen

Wie bekomme ich Geld?

Die Karte ist in Gebiete aufgeteilt. Auf jedem Gebiet steht eine Zahl: So viel Geld bringt es Dir jeden Zug. Das Geld heißt PUs (Produktionseinheiten).

 +   = 5 PUs  →  

Zwei Gebiete mit 3 und 2 bringen 5 PUs: genug für eine Infanterie an Deiner Fabrik.

Mit Deinen PUs kaufst Du neue Einheiten: Soldaten, Panzer, Schiffe und Flugzeuge. Je mehr Gebiete Du hast, desto größer kann Deine Armee werden.

Wie gewinne ich?

Jede Karte sagt, was Du brauchst, meist eine Zahl von Siegstädten oder die Hauptstädte des Gegners. Halte sie, und Du gewinnst.
