Dein erstes Spiel

TripleA ist ein rundenbasiertes Strategiespiel: Jede Nation ist nacheinander am Zug, und jeder Zug hat dieselben Phasen. Du gewinnst, wenn Du genug wichtige Gebiete hältst, meist die Hauptstädte und Siegstädte der Gegenseite.

Ein Spiel gegen den Computer starten

  1. Wähle im Hauptmenü Lokal spielen.
  2. Links siehst Du das ausgewählte Spiel. Change game wählt eine andere Karte; für das erste Spiel ist die kleine Karte Tutorial am besten. Fehlt sie, holst Du sie unter Karten.
  3. Klicke über der Liste der Nationen eine Schnellauswahl wie Spiele Allies: Du spielst alle Nationen dieser Seite, der Computer die anderen.
  4. Klicke Spiel starten.

Zurechtfinden

Die Karte füllt fast das ganze Fenster. Verschiebe sie mit der Maus oder den Pfeiltasten, zoome mit dem Mausrad. Rechts sagt die Zuganzeige, wer am Zug ist, welche Phase läuft und was darin zu tun ist. Darunter zeigen die Reiter die Aktionen der Phase, die Spieler, die Ressourcen und das Gebiet unter der Maus.

Lass Dir Zeit: Der Computer wartet in jeder Phase auf Dich. Bist Du mit einer Phase fertig, klicke Done.
