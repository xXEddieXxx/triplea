Ein Zug, Phase für Phase

Kurz gesagt: kaufen, angreifen, kämpfen, den Rest ziehen, das Gekaufte aufstellen.

Dein Zug hat jedes Mal dieselben Schritte. Sie heißen Phasen. Die Leiste oben im Spielfenster zeigt immer, in welcher Phase Du bist. Bist Du mit einer Phase fertig, klicke Done.

6. Zugende
  1. Kaufen: wähle neue Einheiten und bezahle mit Deinen PUs. Sie warten bis Schritt 5.
  2. Angreifen (Angriffszug): ziehe Einheiten auf feindliches Land oder Meer.
  3. Kämpfen: jeder Angriff wird mit Würfeln ausgefochten.
  4. Ziehen (Nicht-Kampfzug): ziehe Einheiten, die nicht angegriffen haben, und fliege Deine Flugzeuge heim.
  5. Aufstellen: setze die gekauften Einheiten auf Gebiete mit Fabrik.
  6. Zugende: Du bekommst die PUs all Deiner Gebiete. Dann spielt die nächste Nation.

Manche Karten haben weitere Phasen, etwa Forschung. Du siehst sie nur, wenn die Karte sie nutzt.
