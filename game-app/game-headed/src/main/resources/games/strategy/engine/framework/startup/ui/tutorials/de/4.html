Einheiten

Jede Karte hat eigene Einheiten, aber die meisten folgen derselben Idee: Landeinheiten halten Gebiete, Schiffe beherrschen das Meer, Flugzeuge schlagen weit entfernt zu.

  • Infanterie: billig, verteidigt gut, das Rückgrat jeder Armee.
  • Artillerie und Panzer: stärker im Angriff; Panzer ziehen zwei Gebiete weit.
  • Jäger und Bomber: fliegen weit und greifen Land und See an, müssen nach dem Kampf aber landen.
  • Transporter: bringen Landeinheiten übers Meer; sie wehren sich kaum.
  • Schlachtschiffe, Kreuzer, Zerstörer, U-Boote und Träger: kämpfen auf See, manche beschießen vor einer Landung die Küste.
  • Fabriken: Neue Einheiten kannst Du nur in Gebieten mit Fabrik platzieren.

Die Werte sehen

Im Spiel listet Help › Unit Help jede Einheit der Karte mit Kosten, Angriff, Verteidigung und Bewegung. Der Tooltip einer Einheit auf der Karte zeigt dasselbe.
