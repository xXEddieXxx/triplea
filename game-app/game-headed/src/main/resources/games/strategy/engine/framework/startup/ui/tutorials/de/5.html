Dein erstes Spiel

Kurz gesagt: starte ein kleines Spiel gegen den Computer und probiere es aus. Du kannst nichts kaputt machen.

Spiel starten

  1. Klicke im Hauptmenü auf Lokal spielen.
  2. Klicke links auf Change map und wähle die kleine Karte Tutorial. Fehlt sie? Hol sie Dir unter Karten.
  3. Klicke Spiele Allies (oder eine andere Seite): Du spielst diese Seite, der Computer die andere.
  4. Klicke Spiel starten.

Einheiten ziehen

Klicke einen Einheitenstapel an: Jeder Klick nimmt eine Einheit mehr. Die genommenen Einheiten folgen Deiner Maus.

Dann klicke dorthin, wo sie hin sollen. Der rote Pfeil zeigt den Weg.

  • Strg-Klick nimmt den ganzen Stapel. Rechtsklick legt eine Einheit zurück.
  • Vertan? Undo nimmt den Zug zurück.
  • Fertig? Done beendet die Phase.

Umsehen

  • Halte die rechte Maustaste, um die Karte zu verschieben. Strg und das Mausrad zoomen.
  • Die Leiste oben sagt, wer dran ist und was jetzt zu tun ist.
  • Lass Dir Zeit: Der Computer wartet auf Dich.
