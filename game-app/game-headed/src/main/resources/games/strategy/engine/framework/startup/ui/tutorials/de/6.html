Karten

Hunderte von Spielern gemachte Karten gibt es kostenlos: Weltkriege, antike Reiche, Fantasy und mehr. Jede Karte kann mehrere Spiele enthalten, zum Beispiel verschiedene Startjahre.

  1. Wähle im Hauptmenü Karten.
  2. New Maps zeigt, was Du bekommen kannst. Tippe ins Suchfeld, um eine Karte nach Namen oder Kategorie zu finden; klicke eine Karte an, um Bild und Beschreibung zu sehen.
  3. Klicke Install. Der Download läuft im Hintergrund weiter, während Du Dich umsiehst.
  4. Zum Spielen wähle Lokal spielen und dann Change game.

Unter Installed kannst Du Karten entfernen. Bekommt eine Deiner Karten eine neue Version, erscheint sie unter Updates Available.

Eigene Karte bauen? Make your own map unten auf der Kartenseite startet den Karteneditor.
