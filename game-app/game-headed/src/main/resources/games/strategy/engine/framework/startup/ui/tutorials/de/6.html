Mit anderen spielen

Kurz gesagt: klicke im Hauptmenü auf Mehrspieler und wähle, wie Du spielen willst.

  gegen  

Jetzt zusammen spielen

  • In der Lobby spielen: triff Spieler aus aller Welt. Melde Dich an oder spiele als Gast. Tritt einem Spiel bei, das auf Spieler wartet, oder hoste Dein eigenes. Fragen? Frag im Chat.
  • Spiel hosten / Spiel beitreten: spiele mit Freunden. Einer hostet, die anderen treten mit seiner Adresse bei.

Ein Zug nach dem anderen

  • Im Forum spielen: spiele Deinen Zug, wann immer Du Zeit hast. TripleA postet ihn ins Forum, dann macht der nächste Spieler seinen Zug. Du brauchst ein Konto auf forums.triplea-game.org.
  • Per E-Mail spielen: genauso, nur geht Dein Zug per E-Mail.

Bei Forum- und E-Mail-Spielen würfelt ein Würfelserver für alle, so kann niemand schummeln. Klicke auf der Einrichtungsseite einmal Register für die E-Mail jedes Spielers.
