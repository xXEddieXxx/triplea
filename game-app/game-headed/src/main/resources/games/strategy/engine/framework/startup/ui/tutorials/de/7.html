Tipps für Deine ersten Spiele

  • Infanterie ist billig und verteidigt gut. Kaufe vor allem Infanterie, dazu etwas Artillerie und Panzer für den Angriff.
  • Greife mit mehr an. Zwei gegen einen ist sicher. Einer gegen einen ist Glück.
  • Schütze Deine Hauptstadt. Verlierst Du sie, verlierst Du Dein Geld.
  • Plane voraus. Neue Einheiten erscheinen nur an Fabriken. Kaufe dort, wo Du sie brauchst.
  • Probiere aus. Bis Du Done klickst, nimmt Undo Deine Züge zurück. Nur ein ausgefochtener Kampf zählt.
